## S02 — 00:04–00:14 — 기존 AI vs 에이전틱 AI

**스타일:** AB (추상 도형) + UI (작은 컴포넌트)

**비주얼 (V2)** — 화면이 좌/우로 갈라지며 분할 비교
- `00:04.0` 검은 화면이 가운데 세로 분할선으로 갈라짐 (시안 색 얇은 선)
- **왼쪽 패널 (00:04.5–00:09.0)** — 라벨 `기존 AI`
  - 사용자 말풍선 `?` 가 위에서 등장 → 챗봇 말풍선 `!` 가 응답으로 등장
  - 그게 끝. 그 아래 캡션 작게 `→ 답을 준다`
- **오른쪽 패널 (00:09.0–00:13.5)** — 라벨 `에이전틱 AI`
  - 똑같이 사용자 `?` 등장
  - 화면에 **체크리스트**가 펼쳐지며 항목들이 자동으로 `✓` 체크됨:
    - `리서치` → `초안 작성` → `이메일 발송` → `일정 등록`
  - 동시에 그 옆으로 작은 브라우저 창 / 터미널 창 / 캘린더 창이 팝업되어 살짝 흔들림
  - 캡션 작게 `→ 일을 끝낸다`

**오버레이 (V3)**
- 좌 상단 패널 라벨 `기존 AI` (회색)
- 우 상단 패널 라벨 `에이전틱 AI` (옐로우)

**자막 (V4)** — 스크립트 동기화
**VO (A1)** — 보이스오버 본문
**SFX (A3)** — `pop_bubble.wav` (말풍선마다), `tick.wav` (체크마다, 4회), `slide_in.wav` (분할선)
**트랜지션 OUT** — `DISS:8f` (분할선이 가운데로 합쳐지며 페이드)

## S03 — 00:14–00:28 — 에이전트 루프

**스타일:** AB (추상 도형 노드 다이어그램)

**비주얼 (V2)** — 4-노드 순환 다이어그램이 화면 중앙에 자리잡음
- `00:14.0` 한 점에서 4개 노드가 90° 간격으로 펼쳐짐 (둥근 사각형)
- 노드 라벨 (시계 방향, 12시부터):
  1. **계획** (Plan) — 작은 두뇌/체크리스트 아이콘
  2. **실행** (Act) — 커서/손 아이콘
  3. **관찰** (Observe) — 눈 아이콘
  4. **수정** (Reflect) — 화살표 회전 아이콘
- `00:15.5` 시안 색 화살표가 노드 사이를 시계방향으로 한 칸씩 이동. 화살표가 도착한 노드는 옐로우로 점등
- `00:21.0` 한 바퀴 완성. 가운데에 `반복` 텍스트가 펄스
- `00:23.0` 루프 가운데로 작은 도구 아이콘들이 궤도를 그리며 회전: `🌐 Web` `</> Code` `📁 Files` `📅 Calendar`
- `00:26.5` 전체 다이어그램이 살짝 회전하며 다음 신 준비

**오버레이 (V3)**
- 다이어그램 위쪽 캡션: `Agentic AI Loop`
- 화살표 옆 작은 한국어 캡션이 노드별로 0.3s 페이드: `생각`, `행동`, `확인`, `개선`

**자막 (V4)** — 스크립트
**VO (A1)** — 본문

## S04 — 00:28–00:42 — 사용 사례 2×2 그리드

**스타일:** UI (각 카드는 미니 UI 데모)

**비주얼 (V2)** — 화면이 4분할 그리드로 카드가 차례로 슬라이드 인
- `00:28.0` 검은 배경에 회색 그리드 라인 4분할 등장
- 카드는 **왼-위 → 오-위 → 왼-아래 → 오-아래** 순서로 0.4s 간격 등장
  - **카드 1 (왼-위) — 코드 작성 + PR**
    - 작은 터미널 창에 코드가 자동 타이핑 → GitHub PR 머지 아이콘 ✓
  - **카드 2 (오-위) — 리서치 + 보고서**
    - 브라우저 탭 3개가 차례로 열렸다가 PDF 문서 아이콘으로 응축
  - **카드 3 (왼-아래) — 일정 조율**
    - 캘린더 그리드에서 빈 슬롯이 하이라이트 → 시간 약속이 ✓
  - **카드 4 (오-아래) — 데이터 시각화**
    - 표(스프레드시트)가 막대 그래프로 모핑
- `00:38.0` 4개 카드가 모두 등장한 뒤 살짝 동시에 펄스(빛남)
- `00:40.0` 카드들 사이에 점선이 연결되며 `한 명의 에이전트` 라는 캡션이 가운데에 페이드 인

**오버레이 (V3)** — 각 카드 상단 라벨: `코드`, `리서치`, `일정`, `데이터`
**자막 (V4)** — 스크립트

## 비주얼 일관성 규칙 (전 신 공통)

- 컬러: 배경 `#0A0A0A`, 본문 회색 `#A0A0A0`, 강조 옐로우 `#FFD000`, 보조 시안 `#00E0FF`
- 폰트: 본문 Pretendard Bold, 강조 단어는 Pretendard ExtraBold + 살짝 트래킹 -2%
- 모션 인/아웃 이징: `easeOutExpo` (등장), `easeInQuad` (퇴장)
- 모든 신 사이 트랜지션은 4–12 프레임 안. 30fps 기준 **반드시 0.4s 이하** 유지 — 60초 안에 정보 밀도 확보
- BGM: 미니멀 일렉트로닉 루프, 80–95 BPM, S05 빅넘버에서 살짝 볼륨 +2dB 강조
