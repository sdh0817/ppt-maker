# Concept — 에이전틱 AI, 60초 안에 이해하기

## 한 줄 요약
AI는 이제 **"답을 주는 도구"가 아니라 "일을 끝내는 동료"** 다 — 60초 안에 차이·작동 원리·시장 규모까지 보여준다.

## 타깃 / 플랫폼
- 플랫폼: YouTube Shorts (9:16) + Instagram Reels 동시 업로드
- 길이 목표: **60초**
- 시청자: AI 도구는 써봤지만 "에이전트/에이전틱 AI"가 정확히 뭔지 헷갈리는 일반 직장인·개발자
- 사전지식: ChatGPT 정도는 써봤다고 가정. 그 이상의 전문용어는 풀어서 설명.

## 톤 & 매너
- 전문적이지만 빠르고 친근. 강의가 아니라 "한 줄 정리" 느낌
- 비주얼 무드: **모노톤(검정 + 진회색) 베이스 + 옐로우/시안 액센트**, 미니멀 모션
- 모든 신은 1~2개의 메인 비주얼만. 정보 과부하 금지
- 얼굴 미노출 — 키네틱 타이포 + 추상 도형 + UI 화면 캡처로 대체

## 핵심 메시지 (Takeaway)
1. 기존 AI = **답변 머신**, 에이전틱 AI = **실행 동료** (가장 큰 변화)
2. 작동 원리는 **계획 → 실행 → 관찰 → 수정 → 반복** 루프
3. 2028년까지 기업 SW 셋 중 하나에 탑재될 만큼 빠르게 온다 (Gartner)

## 후킹 (첫 3초)
> "AI에게 // **'알아서 끝내줘'** 라고 말할 수 있다면?"

검은 화면 + 타이프라이터 효과로 질문을 띄워 "그게 가능해?" 호기심을 만든다.

## 콜투액션 (마지막)

- 2차: 채널 구독 / 저장

## 보여줄 핵심 비주얼 요소 (시청자 기억점)

1. **분할 비교** — 챗 버블(기존 AI) vs 자동으로 체크되는 체크리스트(에이전틱 AI)
2. **에이전트 루프 4-노드 다이어그램** — Plan → Act → Observe → Reflect 가 실제로 한 바퀴 돈다
3. **2x2 사용 사례 카드** — 코드/리서치/일정/데이터, 각 카드 안에 작은 데모 모션
4. **빅 넘버 스탯** — 0% → 33% 카운터 + 2024 vs 2028 대조 막대
5. **마지막 한 문장** — "쓰는" → "맡기는" 키워드 단어만 남기고 다 페이드
