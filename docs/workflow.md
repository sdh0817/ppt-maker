# 작업 흐름 상세

각 프로젝트는 7단계로 진행됩니다. 사용자(낭독·녹음·원본 영상 제공)와
Claude(기획·스크립트·신별 편집 지시)의 역할이 단계별로 분리되어 있습니다.

---

## 0. 기획 (`00-plan/`)

**담당:** Claude (사용자 지시 기반)
**산출물:** `concept.md`, `storyboard.md`, `edit-plan.md`

### 0.1 `concept.md`
- 주제 한 줄 요약
- 타깃/플랫폼 (예: YouTube Shorts 9:16, 60초)
- 톤·매너 (전문적/캐주얼/유머)
- 영상 길이 목표
- 시청자가 받아갈 핵심 메시지 1~3개

### 0.2 `storyboard.md`
신(scene)별로 표 형식으로 작성합니다. **반드시 모든 신에 타임코드를 부여**합니다.

| Scene | 시작 | 끝 | 길이 | 내용 요약 | 화면(비주얼) | 보이스오버 | 사운드/효과 |
|---|---|---|---|---|---|---|---|
| S01 | 00:00 | 00:04 | 4s | 후킹 질문 | 검은 배경, 타이핑 텍스트 | "왜 이게 안 될까?" | typewriter SFX |

### 0.3 `edit-plan.md`
하이퍼프레임 트랙 단위로 **언제 무엇이 어디에 들어갈지** 명시합니다.

```
[V3] 텍스트 오버레이
[V2] 모션 애니메이션 (메인 비주얼)
[V1] 배경 / 컬러 베이스
[A2] BGM
[A1] 보이스오버
```

각 신마다:
- 어떤 모션 에셋(`04-motion-assets/`의 파일명)을 V2에 올릴지
- 텍스트 오버레이 문구와 폰트 스타일
- 트랜지션(컷/디졸브/푸시 등) 종류와 길이
- 보이스오버 take 번호와 자르기 기준점

> 이 단계가 끝나야 다음 단계로 진행합니다. **편집 단계에서 즉흥 결정 금지.**

---

## 1. 스크립트 (`01-script/`)

**담당:** Claude
**산출물:** `script.md`

- 신 ID(S01, S02 ...)와 시간 길이를 `[S01 / 00:00–00:04]` 형식으로 표시
- 낭독 호흡 단위로 줄바꿈
- 강조하고 싶은 단어는 **굵게**, 잠시 멈춤은 `//` 표기
- 발음이 까다로운 외래어는 옆에 한글 발음 병기

예:
```
[S01 / 00:00–00:04]
왜 이게 // **안 될까요?**
```

## 2. 음성 녹음 (`02-recordings/`)

**담당:** 사용자
**산출물:** `*.mp4` 음성 녹음 파일 + `INDEX.md`

- 파일명 규칙: `S01_take01.mp4`, `S01_take02.mp4`
- 한 신씩 끊어서 녹음하면 후속 편집이 쉬움
- `INDEX.md`에 take별 코멘트 기록 ("S01 take02 채택", 등)

## 2.5 전사 (Whisper Large v3)

**담당:** 자동 (`tools/transcribe.py`)
**산출물:** `02-recordings/transcripts/<stem>.txt | .srt | .json`

녹음이 들어오면 즉시 Whisper Large v3 로 전사합니다. 결과 3종이 생성됩니다.

- `.txt` 전체 텍스트 (스크립트와 비교용)
- `.srt` 자막 (그대로 `06-output/`에서 사용 가능)
- `.json` 단어 단위 타임스탬프 (`edit-plan.md`의 VO 컷 포인트 갱신용)

```bash
# 한 번만:
pip install -r tools/requirements.txt

# 사용:
./tools/transcribe.py projects/<slug>/02-recordings/S01_take02.mp4 \
    -o projects/<slug>/02-recordings/transcripts \
    -l ko \
    --initial-prompt "하이퍼프레임, 모션 그래픽"
```

옵션:
- `-l ko` 한국어 (기본). 다른 언어는 ISO 639-1 코드.
- `--device cuda` GPU 사용 시. 미설정 시 자동 감지.
- `--compute-type float16` GPU 메모리 절약. CPU는 `int8` 권장.
- `--initial-prompt` 도메인 용어 힌트 (전문용어 인식률 향상).

전사 결과의 단어 타임스탬프(json) 를 보고 `00-plan/edit-plan.md`의
VO 컷 포인트(예: `00:00.0–00:03.8`)를 실제 발화 시간으로 갱신합니다.

## 3. 원본 영상 (`03-source/`)

**담당:** 사용자
**산출물:** `*.mp4` 참고/소스 영상 + `INDEX.md`

- 사용자가 얼굴이 나온 영상을 줘도, **얼굴은 최종 결과에 사용하지 않음**
- 동작/제스처/타이밍 참고용으로만 활용
- `INDEX.md`에 어떤 신 참고용인지 명시

---

## 4. 모션 에셋 (`04-motion-assets/`)

**담당:** Claude(스타일 지시) + 사용자/외부 툴(생성)
**산출물:** 얼굴 없는 모션 애니메이션 클립

스타일 옵션 (`docs/motion-style-guide.md` 참조):
- 키네틱 타이포그래피
- 추상 도형 모션
- 일러스트 캐릭터(얼굴 미노출 또는 실루엣)
- UI/화면 캡처 모션

파일명 규칙: `<scene>-<cut>_<설명>.mp4`
예: `S01-C01_hook-text.mp4`, `S02-C03_arrow-flow.mp4`

---

## 5. 편집 (`05-edit/`)

**담당:** 하이퍼프레임에서 사용자가 진행
**산출물:** 하이퍼프레임 프로젝트 파일 + `track-notes.md`

- `00-plan/edit-plan.md`를 그대로 따라 트랙 구성
- 변경사항이 생기면 **반드시 `edit-plan.md`를 먼저 갱신**한 뒤 편집에 반영

---
