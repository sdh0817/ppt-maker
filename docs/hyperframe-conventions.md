# 하이퍼프레임 트랙 / 네이밍 규칙

모든 프로젝트가 동일한 트랙 레이아웃을 사용하면 편집이 일관되고
기획 단계의 `edit-plan.md`가 그대로 트랙 위치 지시서가 됩니다.

## 표준 트랙 레이아웃

| 트랙 | 용도 | 비고 |
|---|---|---|
| V4 | 자막 (캡션) | 최상위. 가독성을 위해 항상 위 |
| V3 | 키네틱 텍스트 / 강조 오버레이 | 짧은 문구, 숫자 강조 |
| V2 | 메인 모션 비주얼 | `04-motion-assets/`의 클립 |
| V1 | 배경 (단색/그라디언트/루프) | 풀 화면 베이스 |
| A3 | SFX | 효과음 |
| A2 | BGM | -18 LUFS 기준 |
| A1 | 보이스오버 | -16 LUFS 기준, 노이즈 제거 후 |

## 신(scene) / 컷(cut) 식별자

- 신 ID: `S01`, `S02`, ... (두 자리 0패딩)
- 컷 ID: `S01-C01`, `S01-C02`, ...
- 한 신 안에서 비주얼이 바뀌면 새 컷

## 마커 / 라벨

하이퍼프레임 타임라인에 다음 마커를 둡니다:
- 빨간색: 신 시작 (`S01`, `S02` ...)
- 노란색: 컷 변경 (`S01-C02`)
- 파란색: 음성 컷 포인트 (take 시작/끝)

## 트랜지션 표기

`edit-plan.md`에서 트랜지션을 다음 표기로 통일합니다:

| 표기 | 의미 | 권장 길이 |
|---|---|---|
| `CUT` | 즉시 컷 | 0f |
| `DISS:8f` | 디졸브 8프레임 | 4–12f |
| `PUSH-L:6f` | 왼쪽 푸시 6프레임 | 4–8f |
| `WHIP:4f` | 휩 팬 | 3–5f |
| `FADE-K:12f` | 검은 화면 페이드 | 8–24f |

## 자막 스타일

- 폰트: Pretendard Bold (없으면 본고딕 Bold)
- 사이즈: 9:16에서 64pt, 16:9에서 48pt
- 색: 흰색 + 외곽선 검정 4px
- 위치: 9:16에서 하단 22%, 16:9에서 하단 12%
