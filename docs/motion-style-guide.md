# 얼굴 없는 모션 스타일 가이드

이 프로젝트는 사용자의 얼굴을 최종 결과에 노출하지 않습니다.
대신 다음 4가지 스타일을 조합해 시각화합니다.

## 1. 키네틱 타이포그래피
- 핵심 단어가 화면을 채우며 들어오고 나가는 방식
- 발화 강세와 동기화 (`script.md`의 **굵은** 단어와 매칭)
- 적합: 후킹, 결론, 통계 강조

## 2. 추상 도형 모션
- 원·선·화살표·격자가 개념을 시각화
- 발화 흐름과 호흡을 맞춰 등장/소멸
- 적합: 프로세스 설명, 비교, 인과 관계

## 3. 일러스트 캐릭터 (얼굴 미노출)
- 얼굴은 ① 뒷모습 ② 실루엣 ③ 모자/마스크로 가림 ④ 화면 밖에서 손만 등장
- 적합: 스토리텔링, 사례 소개

## 4. UI / 화면 캡처 모션
- 코드, 채팅 UI, 슬라이드 등을 모션으로 재구성
- 적합: 데모, 사용 흐름 설명

---

## 신별 스타일 매칭 가이드

`storyboard.md`를 작성할 때 각 신의 "화면(비주얼)" 칸에
**스타일 코드**를 명시합니다:

| 코드 | 스타일 |
|---|---|
| `KT` | 키네틱 타이포 |
| `AB` | 추상 도형 |
| `IL` | 일러스트 (얼굴 미노출) |
| `UI` | UI/화면 캡처 |
| `MIX` | 두 가지 이상 합성 |

예: `KT + AB` = 타이포 위에 추상 도형 모션 합성

## 컬러 / 폰트

다르게 가져갈 경우 해당 프로젝트 `00-plan/concept.md`에 명시.
